# ליאב רפאל שלום · 30

אלבום תמונות ליום הולדת 30. אתר סטטי (HTML/CSS/JS) בלי שלב בנייה. עובד במחשב ובנייד.

## מבנה

```
index.html    – מבנה העמוד
style.css     – העיצוב (רקע מנומר, כרטיסים, גריד, לייטבוקס)
app.js        – בונה את עמודי השנים מתוך photos.js
photos.js     – כאן מוסיפים שנים, תמונות וכיתובים
leopard.svg   – אריח הרקע המנומר
photos/       – קבצי התמונות, בתיקייה לכל שנה: photos/1996/01.jpg
```

## הוספת תמונות

1. שמים את הקבצים ב-`photos/<שנה>/`.
2. ב-`photos.js` מוסיפים או מעדכנים את השנה:

```js
{ year: "1996", title: "השנה הראשונה", photos: [
  { src: "photos/1996/01.jpg", caption: "בבית החולים" },
  { src: "photos/1996/02.jpg" }
] }
```

כדאי להקטין תמונות לרוחב של כ-1600px לפני שמעלים אותן, כדי שהאתר ייטען מהר.

## העלאה לאוויר

1. יוצרים ריפו חדש ב-GitHub ומעלים אליו את כל הקבצים שבתיקייה הזו.
2. ב-[vercel.com](https://vercel.com) לוחצים **Add New › Project**, בוחרים את הריפו ולוחצים **Deploy**.
   אין צורך לבחור Framework או פקודת Build. האתר סטטי.
3. כל push ל-GitHub יעלה את הגרסה החדשה לאוויר באופן אוטומטי.

## בדיקה מקומית

```
npx serve .
```
